Ejercicio 2

Crea la receta de tu postre favorito con:

  • Un h1 con el nombre del postre y un párrafo con el nombre de su país de origen enfatizado
  • Un h2 "Ingredientes" con una lista no ordenada
  • Un h2 "Preparación" con una lista ordenada de, al menos, cinco pasos
  • Los tiempos y temperaturas deben ir resaltados. Escribe los grados usando superíndice (180oC)

Tiramisu

El tiramisu es un postre italiano muy popular.

Ingredientes

  • 250g de queso mascarpone
  • 4 huevos
  • 100g de azúcar
  • 200ml de crema de leche
  • 1 paquete de bizcochos para la receta

Preparación

  1. Bate los huevos con el azúcar hasta obtener una mezcla espumosa.
  2. Añade el queso mascarpone y mezcla bien. Incorpora la crema de leche y sigue batiendo hasta que esté completamente integrada.
  3. En un recipiente, prepara el café con leche a 70oC y sumérgela rápidamente en el líquido. Coloca los bizcochos en una bandeja o plato para servir.
  4. Unta una capa del postre sobre los bizcochos, y repite este proceso hasta agotar los ingredientes.
  5. Deja reposar en el frigorífico durante al menos 4 horas antes de servir.

Ejercicio 3

Crea un glosario usando una lista de definiciones con, al mneos, seis terminos vistos en el curso (HTML, etiqueta, atributo, enlace, navegador, URL...). Además:

  • Los términos que sean siglas deben usar la etiqueta de abreviatura, mostrando su significado al pasar el ratón
  • Las palabras en inglés que aparezcan en las definiciones deben ir marcadas como tecnicismo
  • Separa las líneas largas de alguna definición con un salto de línea

Glosario

HTML
Lenguaje de marcado de hipertexto (HTML) es el lenguaje de marcado que se utiliza para crear páginas web.
Etiqueta
Una etiqueta es un elemento del lenguaje (HTML) que se utiliza para definir la estructura y el contenido de una página web.
Las etiquetas se escriben entre corchetes angulares (< >) y suelen tener un nombre que indica su función.
Atributo
Un atributo es una característica o propiedad que se puede asignar a una etiqueta (HTML) para modificar su comportamiento o apariencia.
Los atributos se escriben dentro de la etiqueta y suelen tener un nombre y un valor.
Enlace
Un enlace es un elemento (HTML) que permite conectar una página web con otra, ya sea dentro del mismo sitio o en otro sitio web.
Los enlaces se crean mediante la etiqueta <a> y suelen tener un texto visible que indica el destino del enlace.
Navegador
Un navegador web es un programa informático que permite acceder a páginas web y navegar por Internet.
Los navegadores interpretan el código (HTML) y muestran el contenido de las páginas web en una interfaz gráfica para el usuario.

URL
Una (URL) es una dirección única que identifica un recurso en Internet, como una página web, una imagen o un archivo. Las (URL) se componen de varios elementos, como el protocolo, el nombre del dominio y la ruta del recurso.
